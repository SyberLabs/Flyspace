# Fonts

Instrument Sans (400/500/600), Instrument Serif (400) and JetBrains Mono
(400/500), Latin subset, copied from the Fontsource npm packages
(`@fontsource/instrument-sans`, `@fontsource/instrument-serif`,
`@fontsource/jetbrains-mono`, v5.3.0). All are licensed under the SIL Open
Font License 1.1. Loaded with `next/font/local` in `src/app/layout.tsx`.
